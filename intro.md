# Data 8 Materials (Spring 2026)

Welcome to the **Data 8: Foundations of Data Science** course materials for Spring 2026 at UC Berkeley.

This book contains:

- **Lectures:** in-class demos and code
- **Labs:** guided exercises
- **Homework:** assignments
- **Sandbox:** a playground notebook with datasets for exploration

Use the sidebar to navigate. To run notebooks interactively, use [DataHub](https://data8.datahub.berkeley.edu) (course students) or the "Run in Binder" link above.

For the full course website, see [Data 8 Spring 2026](https://www.data8.org/sp26/).
